# Historias de Usuario y Sprints

El proyecto se encuentra organizado mediante historias de usuario agrupadas
por módulos funcionales y distribuidas en seis sprints de desarrollo.

## Resumen

| Módulo | Historias |
|--------|-----------|
| Gestión de Usuarios | HUU01 - HUU08 |
| Gestión de Llamadas | HUL01 - HUL14 |
| Gestión de Chats | HUC01 - HUC12 |
| Gestión de Evaluaciones | HUE01 - HUE08 |
| Gestión de Simulaciones | HUS01 - HUS08 |
| **Total** | **50 historias** |
